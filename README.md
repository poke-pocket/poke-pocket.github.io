# POKé POCKET · 掌上像素宝可梦

一款结合 **3D 像素风原野冒险** 与 **复古掌机养成/编队/图鉴** 的纯前端浏览器游戏。

## 主要特性
- **3D 像素原野冒险**：多通道有机 FBM 地形（自然湖泊、缓坡丘陵、绵延山脉）、水系冲浪、场景交互（摘树果、采蘑菇、挖矿石、读路牌）、3D 特写投球收服。
- **复古实体掌机系统**：精灵球盒（支持搜索/筛选/批量放生）、多编队槽位管理、满屏内置地形地图（指南针、自由缩放、无限图钉）、《关都日报》报刊公告、亲密度与超进化外观。

## 本地开发
```bash
npm install
npm run dev
```

## 静态构建
```bash
npm run build
```
